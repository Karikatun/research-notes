# Anonymous material: knowledge compounding in the agent loop

## Material claims

- An engineering task should end by accumulating reusable knowledge.
- A full plugin can keep decisions in a separate corpus and maintain their freshness.

## Verification

The official plugin confirms the mechanism. Automatic use by arbitrary agents and the advantage of a second knowledge corpus are not established.

## Outcome

Adopt task learning as a practice, but do not install a duplicating plugin without a measured gap.
