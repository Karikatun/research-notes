# Figma MCP

## Verdict

The skill is available, but the selected history contains no demonstrated,
repeatable Figma URL → context/assets → production code flow.

## Potential value

Retrieves variables, screenshots, assets, and node context without a manual
description.

## Decision

Use only with a concrete Figma link. Do not call it an adopted practice before
the first validated design-to-code outcome.
