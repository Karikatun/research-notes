# Загружать процессные навыки выборочно

## Желаемый результат

Активировать специализированный процесс только для подходящей задачи и не смешивать перекрывающиеся инструкции.

## Когда применять

Когда задача явно совпадает с областью специализированного навыка: TDD, диагностика, review, проектирование или работа с задачами.

## Критерий успеха

Навык добавляет проверяемый сигнал без лишней церемонии и конфликта правил.

## Ограничения

Постоянная загрузка больших и перекрывающихся наборов увеличивает контекст и может создавать конфликт процессов.

## Пересмотр

Повторно оценить при изменении агентного процесса, потере воспроизводимости или появлении более дешёвой альтернативы.
