# Сокращать терминальный вывод без потери сигнала

## Желаемый результат

Фильтровать шумный вывод, сохраняя путь к полному результату для диагностики.

## Когда применять

Для длинного и повторяющегося вывода Git, тестов, CI и процессов, когда полный текст не нужен для следующего решения.

## Критерий успеха

Контекст уменьшается без роста повторных запусков из-за скрытой информации.

## Ограничения

Не фильтровать точный JSON, forensic-логи и неизвестные форматы; полный вывод должен оставаться доступным.

## Пересмотр

Повторно оценить при изменении агентного процесса, потере воспроизводимости или появлении более дешёвой альтернативы.
