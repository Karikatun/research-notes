# Анонимный материал: интерактивные HTML-планы для работы с агентом

## Утверждения материала

- Специализированный skill помогает агенту оформить сложную задачу в HTML.
- Такой артефакт может объединять ограничения, прототипы, развилки, архитектуру,
  API-форматы, риски и пошаговый план.
- Достаточно попросить агента использовать skill в исходном промпте.

## Проверка

Официальный skill действительно предназначен для планов, сравнений, диаграмм,
таблиц и отчётов. CLI открывает созданный агентом HTML в локальном редакторе,
позволяет аннотировать элементы и текст, редактировать Mermaid-схемы и возвращает
очередь замечаний агенту через polling.

Не подтверждено, что инструмент сам улучшает полноту или корректность архитектуры
и способен надёжно решить сложную задачу «с одного промпта». Он предоставляет
формат визуализации и feedback loop; содержание формирует агент.

Локальный режим не требует облака, но установка через неприкреплённый `npx -y`,
постоянный hook, недоверенный HTML и отдельная публичная по умолчанию команда
публикации требуют ограничений.

## Итог

Провести локальный пилот на одном несекретном сложном плане, сравнив его с
обычным Markdown или встроенной визуализацией. Не устанавливать глобально и не
публиковать артефакт. Решение принимать по времени до согласования, числу циклов,
точности привязки замечаний и переделке.
