# Навык ручного security review

## Вердикт

Принят как локальный навык ручного анализа угроз с автоматическим выбором
глубины review и обязательным дифференциальным проходом для существенного
security-sensitive diff.

## Роль в агентной разработке

Закрывает слепые зоны сканеров: авторизацию, IDOR, повторное воспроизведение,
гонки, конфиденциальность, восстановление, границы эксплуатации и раскрытие
данных. Маршрутизирует задачу в полный, целевой или семантический режим по
достижимому поведению, а не по удобству агента, и связывает findings с
проектными контрактами и regression guards.

## Доступ и происхождение

Локальный проектный навык с доступными исходниками; публичной официальной ссылки
нет. Его правила принадлежат ответственному репозиторию и не расширяют сетевые,
Git или scanner-полномочия агента.

## Наблюдаемое применение

В независимых ограниченных пилотах baseline review сравнивался с проходом по
истории controls, blast radius, соседним вариантам и независимому опровержению.
Добавка дала принятые недублирующие сигналы и regression guards; отдельная
стоимость не измерялась.

## Ограничения

Субъективная проверка не доказывает отсутствие угроз. Широкий history и variant
search может создать лишние гипотезы; каждая требует проверки достижимости и
дедупликации. Малому изменению, доказанно ограниченному семантикой, полный
review не нужен.

## Решение

Оставить обязательным для security-sensitive изменений вместе с
интеграционными и concurrency-тестами и уместными scanners. Повторно оценить,
если меняются project contracts или маршрутизация, исчезает добавочный сигнал
относительно baseline либо церемония начинает преобладать над полезными
findings.
