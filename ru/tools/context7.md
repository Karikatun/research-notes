# Context7

## Вердикт

Принят как основной источник актуальной документации библиотек и SDK.

## Задача и потенциальная польза

Снижает риск ответа по устаревшей памяти модели: сначала разрешает точный
идентификатор библиотеки, затем возвращает подходящий фрагмент документации.

Технически успешный вызов не доказывает правильность выбранной версии или
рекомендации.

## Реальная польза

Использовался при выборе библиотеки для ввода телефона и работе с React,
Next.js, Prisma и другими API. Не создаёт второй локальный источник истины.

## Сбои и ограничения

- Один зафиксированный технический сбой.
- Может выбрать ответвление сообщества или документацию не той версии.
- Запрос уходит внешнему сервису: передавать секреты и закрытый код запрещено.

## Решение

Использовать по умолчанию для внешних API и библиотек, сверяя версию с файлом
фиксации зависимостей. Чувствительные к безопасности контракты дополнительно
проверять по первичному источнику.

## Контракт телеметрии

Единица — завершённое событие точного инструмента или команды в доступных локальных журналах задач. Подсчёт отделяет вызов, техническое завершение и принятый результат; сырые журналы не публикуются. Агрегат пересчитывается тем же фильтром после накопления нового значимого набора событий или изменения схемы журнала.
