# Figma MCP

## Вердикт

Навык доступен, но в выбранной истории нет подтверждённого устойчивого процесса
«ссылка Figma → контекст и ресурсы → промышленный код».

## Потенциальная польза

Получение переменных, снимков экрана, ресурсов и контекста узла без ручного
пересказа.

## Решение

Использовать только при конкретной ссылке Figma. До первого проверенного
результата переноса дизайна в код не считать принятой практикой.
