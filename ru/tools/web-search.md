# Веб-поиск

## Вердикт

Принят для изменчивых фактов и первичных внешних источников.

## Измеримые данные и реальная польза

В выбранной истории найден 81 прямой вызов веб-инструмента. Он использовался для
официальной документации, сведений о выпусках, фактов о безопасности и проверки
материалов из видео и статей.

## Ограничения и решение

Результат поиска не является доказательством; предпочтительны первичные
источники, а цитата должна подтверждать конкретное утверждение. Не использовать
вместо Context7 для документации библиотек или вместо локального кода для фактов
о проекте.

## Контракт телеметрии

Единица — завершённое событие точного инструмента или команды в доступных локальных журналах задач. Подсчёт отделяет вызов, техническое завершение и принятый результат; сырые журналы не публикуются. Агрегат пересчитывается тем же фильтром после накопления нового значимого набора событий или изменения схемы журнала.
